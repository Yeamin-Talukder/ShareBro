**ShareBro for Mac 1.10.1** is the first Mac version GitHub builds, tests and publishes by itself. It works just like 1.10.0, and it's the first update you can install from inside the app. It keeps your people, names and settings.

This is a **preview**: please [report anything odd](https://github.com/Yeamin-Talukder/ShareBro/issues).

## Download

| File | For |
|---|---|
| **`ShareBro-1.10.1-macos.dmg`** | Installing: macOS 12 Monterey or newer, Apple Silicon and Intel Macs |
| `ShareBro-1.10.1-macos.zip` | The same app, zipped. The app's own updater uses this one |

**Already have 1.10.0?** Open **Settings › Software update** and click **Restart and update**.

**New install:**

1. Download the **.dmg** and open it. In the window that appears, drag **ShareBro** onto **Applications**, then eject the disk.
2. The app isn't signed by Apple yet, so the first time macOS says it **can't check it for malicious software**. Click **Done**, then open **System Settings › Privacy & Security**, scroll down and click **Open Anyway** next to ShareBro. You only do this once.
3. If macOS asks whether ShareBro may accept incoming network connections, click **Allow**, so your phone can find the Mac.

## What's new

- **Built in the open.** Every release is now built and tested by GitHub from the public code, with checksums the in-app updater checks before installing.
- **Updates from inside the app.** 1.10.0 can update itself to this version from **Settings › Software update**.

Get the phone app from [ShareBro 1.10.1](https://github.com/Yeamin-Talukder/ShareBro/releases/tag/v1.10.1).
