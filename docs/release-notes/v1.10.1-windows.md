**ShareBro for Windows 1.10.1** is the first version GitHub builds, tests and publishes by itself. On your PC it works just like 1.10.0. It installs over 1.10.0 (or updates from **Settings › Software update**) and keeps your people, names and settings.

This is still a **preview**: please [report anything odd](https://github.com/Yeamin-Talukder/ShareBro/issues).

## Download

| File | For |
|---|---|
| **`ShareBro-1.10.1-windows-setup.exe`** | Windows 10 and 11, 64-bit |

If you installed an earlier version "for all users", choose that again so it updates the same copy.

**"Windows protected your PC"?** The installer isn't signed yet. Click **More info › Run anyway**.

## What's new

- **Built in the open.** Every release is now built and tested by GitHub from the public code, with checksums the in-app updater checks before installing.
- **ShareBro for Mac** is out too, so your PC can share with Macs running ShareBro.

Get the phone app from [ShareBro 1.10.1](https://github.com/Yeamin-Talukder/ShareBro/releases/tag/v1.10.1).
