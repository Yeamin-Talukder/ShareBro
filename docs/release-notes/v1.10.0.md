**ShareBro 1.10.0** lets you choose where received files are saved. It installs over 1.9.2 (or updates from inside the app) and keeps your people, names and settings.

## Which file do I download?

| File | For |
|---|---|
| **`ShareBro-v1.10.0-arm64-v8a.apk`** | **Almost every phone from the last ~7 years.** Start with this one. |
| `ShareBro-v1.10.0-armeabi-v7a.apk` | Older 32-bit phones |
| `ShareBro-v1.10.0-x86_64.apk` | Emulators and Chromebooks |

Requires Android 9 or newer. On a Windows PC, get [ShareBro for Windows 1.10.0](https://github.com/Yeamin-Talukder/ShareBro/releases/tag/v1.10.0-windows).

## New

- **Choose where received files go.** In **Settings › Sharing**:
  - **Received photos and videos:** pick any folder inside DCIM or Pictures (for example DCIM/Camera, to keep them with your own photos, or a new Pictures/Trips folder). They still show up as an album and are still scanned for faces. The default stays the **ShareBro** album.
  - **Received files:** pick any folder inside Download or Documents. The default stays **Download/ShareBro**.
  - The system folder picker lets you make a new folder on the spot. Android doesn't let apps save received files to a memory card, or outside those folders; ShareBro tells you if you pick one of those.
- The Receive page and notifications now say where your files actually went.

Android 9 always puts received photos in Pictures, so there only the files folder can be changed.
