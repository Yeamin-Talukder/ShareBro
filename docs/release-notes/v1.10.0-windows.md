**ShareBro for Windows 1.10.0** lets you choose the folder received files are saved in. It installs over 1.9.2 and keeps your people, names and settings.

This is still a **preview**: please [report anything odd](https://github.com/Yeamin-Talukder/ShareBro/issues).

## Download

| File | For |
|---|---|
| **`ShareBro-1.10.0-windows-setup.exe`** | Windows 10 and 11, 64-bit |

If you installed an earlier version "for all users", choose that again so it updates the same copy.

**"Windows protected your PC"?** The installer isn't signed yet. Click **More info › Run anyway**.

## New

- **Save received files anywhere.** **Settings › Sharing › Save received files to** opens a folder picker: any folder on any drive, including a USB drive or a network share. The button next to it opens the folder, and **Use the Downloads folder again** goes back to `Downloads\ShareBro`.
- The Share page says where incoming files are being saved.

Your phone can choose its own folders too with [ShareBro 1.10.0](https://github.com/Yeamin-Talukder/ShareBro/releases/tag/v1.10.0).
