**ShareBro 1.10.1** is the first version GitHub builds, tests and publishes by itself. On your phone it works just like 1.10.0. It installs over 1.10.0 (or updates from inside the app) and keeps your people, names and settings.

## Which file do I download?

| File | For |
|---|---|
| **`ShareBro-v1.10.1-arm64-v8a.apk`** | **Almost every phone from the last ~7 years.** Start with this one. |
| `ShareBro-v1.10.1-armeabi-v7a.apk` | Older 32-bit phones |
| `ShareBro-v1.10.1-x86_64.apk` | Emulators and Chromebooks |

Requires Android 9 or newer. For computers: [ShareBro for Windows 1.10.1](https://github.com/Yeamin-Talukder/ShareBro/releases/tag/v1.10.1-windows) and [ShareBro for Mac 1.10.1](https://github.com/Yeamin-Talukder/ShareBro/releases/tag/v1.10.1-macos).

## What's new

- **Built in the open.** Every release is now built and tested by GitHub from the public code, and each APK is checked against ShareBro's signing key before it's published, so updates always install over your current app.
- **ShareBro for Mac.** Your phone can now send to, receive from and sync people with a Mac too.
